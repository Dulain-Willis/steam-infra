AWS Networking Glossary

Quick reference. Terms as used across steam-infra lessons — see Lesson 1.

VPC (Virtual Private Cloud)

Isolated private network space in AWS, defined by a CIDR block. Nothing outside it is reachable unless explicitly connected.

CIDR block

a.b.c.d/n — an IP range. n = fixed prefix bits; 32-n bits free. Smaller n = bigger range. /16 = 65,536 addresses, /24 = 256.

Availability Zone (AZ)

One physically distinct datacenter cluster within an AWS region. Used for fault isolation — spread resources across AZs so one outage doesn't take everything down.

Subnet

A CIDR sub-range carved out of a VPC. Always pinned to exactly one AZ. "Public" or "private" is not inherent — determined entirely by its route table (see below).

Internet Gateway (IGW)

AWS-managed component attached to a VPC that provides the only path to/from the public internet. Necessary but not sufficient — a route table must point traffic at it.

Route table

List of rules: destination CIDR → target. Every subnet uses one route table — either an explicit association, or the VPC's implicit main table by default.

0.0.0.0/0

The "default route" — matches any destination not covered by a more specific rule. A route table with 0.0.0.0/0 → igw is what makes a subnet "public."

Main route table

Every VPC has one implicit default route table. Any subnet without an explicit association uses it. Has no internet route by default — private by default.

Route table association

Explicit link binding a subnet to a specific (non-main) route table, overriding the main-table default for that subnet only.

map_public_ip_on_launch

Subnet setting: auto-assigns a public IP to instances launched there. Only useful if the subnet's route table also has an internet route — otherwise the public IP goes nowhere.

Bastion host

Single hardened instance in a public subnet acting as the sanctioned entry point into private subnets. Shrinks the internet-facing attack surface to one box instead of exposing every private service.

Security group

Stateful virtual firewall attached to an instance/interface. Allow-only rules for inbound and outbound traffic. Independent from route tables — a packet needs a route and a security-group allow to arrive.

IAM role

A set of permissions with no permanent owner — assumed temporarily by whatever's trusted to assume it (contrast: an IAM user has permanent credentials).

Trust policy (assume role policy)

Defines who is allowed to assume a role. Separate from what the role can do once assumed — that's the attached permissions policy.

Managed policy

AWS-authored, AWS-maintained bundle of permissions you attach to a role/user, e.g. AmazonSSMManagedInstanceCore.

Instance profile

Thin wrapper holding one IAM role, which is what an EC2 instance actually attaches (it can't attach a role directly).

SSM Session Manager

AWS Systems Manager feature giving shell access to an instance via an outbound agent connection — no SSH, no inbound port needed.

AMI (Amazon Machine Image)

A bootable disk snapshot — OS plus whatever's baked in — that an EC2 instance launches from.

RDS (Relational Database Service)

AWS-managed database engine (e.g. Postgres) — AWS handles patching/backups/storage, you get a normal DB endpoint.

DB subnet group

A set of subnets (spanning AZs) RDS is allowed to place its instance in — you don't pick one subnet directly.

source_security_group_id

Security group rule source that names another security group instead of a CIDR block — an identity check ("anything wearing SG X"), not a location check. Survives the source's IP changing.

SSM port forwarding

SSM Session Manager document (AWS-StartPortForwardingSessionToRemoteHost) that tunnels a local port to a remote host through an instance, over the same outbound agent connection as a shell session — the instance relays bytes, it doesn't run the client.
